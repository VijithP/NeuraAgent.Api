# Read Jira Issue

Act as a software support engineer.

The issue must be retrieved from Jira.

## Required Information

Read the Jira ticket and collect:

- Issue Key
- Summary
- Description
- Issue Type
- Priority
- Status
- Reporter
- Assignee
- Labels
- Components
- Acceptance Criteria
- Comments
- Attachments metadata

## Important

Read the complete ticket before diagnosing the issue.

Pay particular attention to:

- error messages
- API URLs
- stack traces
- expected behavior
- actual behavior
- reproduction steps
- recent developer comments

Do not modify source code during this step.
