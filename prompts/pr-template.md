# Pull Request Preparation

Prepare a pull request for the completed issue.

Do not create the PR unless human approval
has been provided.

## PR Title

Use:

Fix: {short description}

Example:

Fix: configure CORS for Angular client

## PR Description

Generate the following format:

# Issue

Issue ID:
Customer Issue:

# Root Cause

Explain the identified root cause.

# Changes

List the files changed and explain why.

# Validation

Build:
Tests:

# Risk

Risk Level:

# Testing Instructions

Explain how a developer can verify the fix.

# Files Changed

List all changed files.
